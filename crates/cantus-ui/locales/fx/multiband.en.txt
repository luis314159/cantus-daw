# Toolbar
mb.mode.0 = Dynamic
mb.mode.1 = Split
mb.mode.0_tip = No split: the input goes through one shelf per crossover that moves only while a band moves. Zero latency, and the input to the bit while no band acts.
mb.mode.1_tip = A true split (Linkwitz–Riley): each band is a band of the signal, and together they sum flat. A wire while no band can act.
mb.mode.2 = Linear
mb.mode.2_tip = A true split with linear-phase crossovers: no phase shift at all, and the bands at unity are the input to the bit, delayed. Costs 48 ms of latency at 48 kHz, which the host compensates.
mb.slope_tip = Crossover slope. In Split mode, 6 dB/oct sums to the input exactly; steeper slopes separate the bands more and add phase shift at the crossovers.
mb.listen.0 = Output
mb.listen.1 = Delta
mb.listen.2 = Key
mb.listen.0_tip = What Multiplex puts out.
mb.listen.1_tip = Only what the bands change: what is taken away, or added in the upward modes.
mb.listen.2_tip = What the detectors hear: each band's key through its filter (only the soloed bands, if any are).
mb.latency = Latency {ms} ms · {n} smp
mb.latency_none = No latency
mb.latency_tip = The delay Multiplex adds: the longest lookahead of any band. The host compensates it.
mb.bands = {n} of {max} bands
mb.key = Sidechain
mb.key_none = None
mb.key_tip = A strip whose output the bands that ask for it listen to, instead of their own input. No send to set up.
mb.key_bands = {n} bands listen to it
mb.key_hint = Pick a strip to key bands from another sound.
mb.via_split = Heard through the split
mb.via_split_tip = Solo and mute need real bands, so while one is on, Dynamic mode is heard through the split.
