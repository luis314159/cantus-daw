# ADR 0007 — Internationalization from day one

**Status:** Accepted · **Date:** 2026-09-07

No user-visible string is written inline in the UI. `cantus_ui::i18n::t(key)` looks up a
key in the active locale table (English and Spanish ship in the MVP). Locale tables are
plain `key = "value"` files under `crates/cantus-ui/locales/` so translators need no Rust.
Fluent (`fluent-rs`) replaces the table once plurals/gender are needed; the call site stays
the same. A unit test asserts every key in `en` exists in every other locale.
