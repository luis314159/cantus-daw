Chorda: every string alone

Each string of each key A0 to C8 is struck alone inside the instrument at velocities 0.3, 0.6 and 0.9. The other strings of the key are muted the way a piano technician mutes them with felt: they stay on the bridge but do not sound. The horizontal polarisation loop of the one- and two-string keys is measured the same way. Each string is compared with the pitch it was designed to have: the keyboard's curve plus that string's designed unison offset. These are measurements of the model. Nobody has listened to them yet.

Error against the designed pitch

The ear's pitch of each string alone, in cents. Zero means the string is exactly where it was designed to be. The green band is the tolerance the tests hold that string to: one cent up to E6 and 2.5 cents above it, the same as for a whole key. A string of a unison also gets what the design itself puts between one string alone and its key (the technician's table and part of the bridge's pull). The grey bars show each whole key against its curve.

Every key, every string

Designed offset: the string's designed detune from the curve, in cents. The three error columns give the ear's pitch of that string alone minus its designed pitch, one column per velocity, as the instrument plays it. "Noises off" is the same measurement with the action's noises (the key's thud, the hammer's blow in the frame, the damper landing) turned off. The thud is the same whichever string sounds, so a quiet string alone hears it relatively louder than its key does. Fundamental: the first partial's error at velocity 0.9. Between G#1 and C2 the thud pulls that weak partial by tens of cents; with the noises off it is within 2 cents. Predicted: how much the bridge and the technician's table account for. Key whole: the whole key, all its strings sounding, against the curve. Red cells are outside the tolerance.
