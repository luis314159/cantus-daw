# The feature matrix — its rows (round 37)

One row per feature a top DAW is judged on, grouped as BACKLOG §3 and §0.2 group them. Each
DAW's column holds **have**, **partial** (with what is missing), **missing**, or for Cantus
also **better** (with the measured or stated reason). Every cell for another DAW cites its
current manual or the vendor's own page (version and URL); nothing from memory.
