The owner (2026-11-20): **Chorda is pronounced like "corda" — KOR-da** (Latin *ch* = k), in
English and Spanish. The other Latin names follow the same hard consonants: Cantus KAN-tus,
Tympanum TIM-pa-num, Fides FEE-des, Nitor NEE-tor.

**How to apply:** any narration, TTS script or video gives the engine a spoken spelling
("Korda") and checks the transcript for it. See [[decision-video-onda-lapis]].
