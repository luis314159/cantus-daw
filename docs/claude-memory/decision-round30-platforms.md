The owner, 2026-10-20 (round 29): "la idea es tener un release para Windows, Linux y Mac al
final". Chosen: finish round 29 as planned (Windows release, push), then **round 30 = the
platform round**: Linux (PipeWire/JACK, RT priority, plug-in windows X11/Wayland, isolation
helper, AppImage) and macOS (CoreAudio + workgroups, Apple silicon and Intel, Cocoa plug-in
windows, isolation without futex, signing + notarisation, .dmg) — releases for all three at
its end. Also asked about iOS: recorded in BACKLOG §2 (iPad after macOS: touch mode, AUv3
hosting/export, App Store licence exception).

**Why:** the market (Ableton/Logic/Bitwig users) is on Mac; Linux is cheap and close.

**How to apply:** for macOS the owner can borrow a Mac and, if needed, buy the Apple
Developer Program and more GitHub Actions minutes (or make the repo public — minutes are
free then; history cleanup of research screenshots first, BETA.md). Plan round 30's brief
around a borrowed Mac session for real-audio tests. See [[round-29]], [[goal-best-daw]].
