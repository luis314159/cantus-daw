On 2026-10-07, after several ideas in a row (more effects, a Melodyne-class editor, a
real-time auto-tuner), the owner said: "Solo agrega todas las ideas al backlog para que más
adelante podamos irlos trabajando."

**Why:** ideas come while a round is running; they want them captured, not designed or
debated now — the work is picked up later from the backlog.

**How to apply:** add each idea to `docs/BACKLOG-excellence.md` (a section or row with the
reference products and a "done when", plus the Spanish summary line), commit it on the
current integration branch so it travels with the next push, and answer in one or two
lines. Do not interrupt the running round for it. See [[round-22]].
