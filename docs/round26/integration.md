## Decisions taken by the integrator

- **Schema 24** (sampler): controller-triggered zones must not be read by an older build as
  keyed zones (it would play pedal noises on keys). The migration writes nothing;
  `fixtures/v24.cantus`. The contract said "no schema change"; the exception is justified
  in ADR 0050.
- **The cache flush after the rename, not before** (ADR 0050): a flush before the rename
  doubled a first load (9.1 s → 20.7 s per GB written); damage from a crash in between is
  caught by per-block checksums and decoded again.
- **The voices' reader wake** is a scoped exception to ADR 0005 rule 3 (ADR 0050 §4):
  non-blocking, only when a voice needs the reader sooner than its next look, counted in
  `EngineStats::stream_wakes`; 0 wakes in ordinary playback, measured.
- **The RVR1960 text out of the build** (ADR 0049; `tools/public/rvr1960-out-of-tree.patch`):
  the file stays in the repository, the build no longer includes it while not permitted;
  a compile-time assertion stops anyone permitting it without bringing the file back.
- **Round 26 goes to master as one squashed commit**: the public builder's first commits
  wrote the owner's work address into documents (removed since); squashing keeps those
  blobs out of master's history.

## Lessons kept (also in the memory)

- **The shipped app never calls `CantusApp::new`.** Start-up is `cantus_ui::run` →
  `boot::Boot` → `CantusApp::assemble`; two features (the font fallback, the sample-cache
  services) were wired only in `::new` and were dead in the real app until a review read
  the start-up path. Tests now fail if they leave the boot path.
- **The WSL disk lives on C:.** `tools/wsl/check.sh` built with full debug info; its target
  reached 126 GB and filled C:. It now builds as CI does (no debug info, no incremental).

Two tests failed only on Linux on the first full run and were fixed by the integrator:
`rt_memory`'s streaming case still required a reader wake that the final wake rule no longer
makes (it now bounds them; zero wakes in ordinary playback is held by `inst_stream`), and the
CI path guard read `shoot_readme`'s *output* folder as an input (examples' run-time reads no
longer count). `night_budget`'s one flaky failure was the status line rebuilding for engine
numbers it does not show without a device (mixer builder; 40 of 40 under load since).
