**Cantus 0.1.0-beta.5 — a fix for Linux.** A free, open-source digital audio workstation
for Windows, macOS and Linux, made by Luis Ángel Almazán
([lalmazan.com](https://lalmazan.com)).
*"Whatever you do, work heartily, as for the Lord" — Colossians 3:23.*
[Español abajo](#cantus-010-beta5--una-corrección-para-linux).

## Fixed

- **Linux: plug-ins from other makers no longer die as they load.** In 0.1.0-beta.4 a
  plug-in set to run in its own process (the default for CLAP and VST3 plug-ins) could be
  ended by the system a moment after it started, and showed as crashed. The process that
  hosts it is now started by the thread that watches it for its whole life. If you set your
  plug-ins to *Within Cantus* to get around it, you can set them back.
- Windows: nothing changes for you in this release beyond what beta.4 brought.

## Install

| System | File | |
|---|---|---|
| Windows 11, x64 | `Cantus-0.1.0-beta.5-windows-x64-setup.exe` | Run it; no administrator rights. Also a portable zip. |
| Linux x86-64 (Ubuntu 22.04 or newer, or alike) | `Cantus-0.1.0-beta.5-linux-x86_64.AppImage` | `chmod +x` it and open it; nothing to install. |

Each file is also published under a name without the version (`Cantus-windows-x64-setup.exe`,
`Cantus-linux-x86_64.AppImage`), the names the website's buttons link to. Check a download
against `SHA256SUMS.txt` if you like: `Get-FileHash <file>` on Windows, `sha256sum <file>` on
Linux. The Windows installer is not code-signed yet: choose *More info ▸ Run anyway*.

**Updating:** Cantus tells you this version is out. On Windows it installs when you close
Cantus; an AppImage replaces itself (the old one is kept beside it, ending in `.old`, until
the new one starts).

**macOS** comes next, after a session on a real Mac.

## Cantus 0.1.0-beta.5 — una corrección para Linux

### Corregido

- **Linux: los plug-ins de otros fabricantes ya no mueren al cargarse.** En la 0.1.0-beta.4
  un plug-in configurado para correr en su propio proceso (lo predeterminado para los
  plug-ins CLAP y VST3) podía ser terminado por el sistema un momento después de arrancar, y
  aparecía como caído. Ahora el proceso que lo aloja lo arranca el hilo que lo vigila durante
  toda su vida. Si pusiste tus plug-ins en *Dentro de Cantus* para evitarlo, puedes volver a
  cambiarlos.
- Windows: en esta versión no cambia nada para ti respecto a la beta.4.

### Instalación

| Sistema | Archivo | |
|---|---|---|
| Windows 11, x64 | `Cantus-0.1.0-beta.5-windows-x64-setup.exe` | Ejecútalo; sin permisos de administrador. También hay un zip portátil. |
| Linux x86-64 (Ubuntu 22.04 o más nuevo, o similar) | `Cantus-0.1.0-beta.5-linux-x86_64.AppImage` | Hazlo ejecutable (`chmod +x`) y ábrelo; nada que instalar. |

Cada archivo se publica también con un nombre sin la versión
(`Cantus-windows-x64-setup.exe`, `Cantus-linux-x86_64.AppImage`), al que apuntan los botones
de la web. Si quieres, compara la descarga con `SHA256SUMS.txt`: `Get-FileHash <archivo>`
en Windows, `sha256sum <archivo>` en Linux. El instalador de Windows aún no está firmado:
elige *Más información ▸ Ejecutar de todas formas*.

**Actualizar:** Cantus te avisa cuando sale esta versión. En Windows se instala al cerrar
Cantus; un AppImage se reemplaza a sí mismo (el anterior se guarda a su lado, terminado en
`.old`, hasta que arranca el nuevo).

**macOS** viene después, tras una sesión en una Mac real.
