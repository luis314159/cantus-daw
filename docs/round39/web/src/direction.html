      • First on screen

        Cantus's window is ready 2.4× sooner than REAPER's and 3.3× sooner than FL Studio's, and it is done working sooner too.

      • Quiet when nothing plays

        At rest Cantus uses less CPU than both: every channel whose effects hear silence stops running them, to the same bits.

      • Still to win

        Memory: Cantus holds more than both, because its audio engine reserves in advance what its largest session could need. Making that reservation grow with the song is the work ahead.
