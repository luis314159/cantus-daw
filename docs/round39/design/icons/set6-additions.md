# Set 6 — additions (the owner, 2026-11-09)

The owner reviewed the 82-icon library and asked for it to be complete:
- **"Nos faltan címbalos"**, i.e. cymbals of every kind;
- **clave de sol, clave de do**;
- **guitarra de 12 cuerdas**;
- **ride**;
- and **"analiza cuáles faltan … 0 flojera, déjalo muy muy completo"**.

The cajón already exists; keep it.

This list was built against several references:
- the orchestra's sections;
- popular and electronic music's track roles;
- Latin, Mexican and world instruments;
- music notation;
- sound design;
- mixing roles.

Every glyph is drawn the same way as the rest of set 6:
- a clear silhouette at 14/16 px;
- the family grammar;
- 2–3 variants for the hard ones, picked by looking at 1:1 and 4×;
- an English and a Spanish name in `spec-tracks.md`, so search finds both.
