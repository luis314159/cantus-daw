# The Cantus name and logos

"Cantus", the Cantus logos and the mark (the C of waves with the playhead) are trademarks
of **Luis Ángel Almazán** (registration in progress — ADR 0047). The code is free
software; the name and the logos are what tell people a copy of Cantus is the real one,
so they are kept for the project's own releases.

## Free to do, no permission needed

- Use the name to talk about Cantus truthfully: reviews, tutorials, videos, courses,
  articles, "made with Cantus", "a preset pack for Cantus", "works with Cantus".
- Share **unmodified** official builds of Cantus, with their name and logos, for free.
- Package Cantus for an operating system or a distribution (Linux packages, Flathub,
  winget…) when the build is made from unmodified official sources — patches needed
  only to build or to fit the system are fine; tell us about them.
- Use the logo to link to cantusdaw.com, at its proportions and colours.

## Not without written permission

- Calling a **modified** version "Cantus", or using the logos on it. A fork is welcome —
  the licence allows it — but under its own name and logo; it may say "based on Cantus".
- Using the name or logos in a product's, company's or domain's name, or in a way that
  suggests the project endorses something it does not.
- Selling Cantus, or anything with its name or logos, as if it came from the project.
